## Обо мне / About Me

</div>

Меня зовут **Максим**. Я AI-инженер из России. Разрабатываю локального AI-агента **Nexus** с долговременной памятью, RAG-поиском и инструментами. Работаю полностью офлайн, без облачных зависимостей.

Моя цель - создавать **инструменты, которые порождают инструменты** (философия TFT). Я хочу не просто использовать AI, а **исследовать и создавать** новые технологии для AI.

My name is **Maksim**. I'm an AI Engineer from Russia. I build a local AI agent **Nexus** with long-term memory, RAG search, and tools. It works fully offline, without cloud dependencies.

My goal is to build **tools that build tools** (TFT philosophy). I want not just to use AI, but to **research and create** new technologies for AI.

<div align="center">

### Уже умеет / Current Features

</div>

- **Долговременная память** - SQLite + векторный поиск (RAG)
- **Семантический поиск** - ищет по смыслу, а не по словам
- **База знаний** - 8+ форматов: PDF, DOCX, CSV, HTML, TXT, MD, JSON, GO
- **Интернет-поиск** - DuckDuckGo
- **Работа с файлами** - чтение, запись, открытие
- **Автозапуск** - сам поднимает Ollama и llama-server
- **Windows Terminal** - перезапускается в современном терминале
- **CI/CD** - автоматические релизы в Telegram и VK
- **Замер скорости** - токены/сек после каждого ответа

<br>

<div align="center">

### Будет уметь / Planned Features

</div>

- **Агентный цикл (tool calling)** - сам решает, какие инструменты использовать
- **Управление Git** - коммиты, теги, пуш из агента
- **Генерация файлов** - `.txt`, `.md`, `.go`, `.json`, `.html` по запросу
- **Управление ПК** - открытие приложений, работа с окнами
- **Голос** - распознавание речи (STT) + синтез (TTS)
- **Зрение** - анализ скриншотов
- **Самообучение** - RAG + дообучение (LoRA)
- **NetScope** - диагностика сети простым языком
- **MovieTracker** - трекер фильмов с AI-рекомендациями
- **Mobile** - Android / iOS
